# 验收清单

- [x] 报告中重要邮件排在一般邮件之前，邮件组内按接收时间倒序。
- [x] 报告重要概述包含每一封重要邮件，不截断为前三封。
- [x] 报告链接显示为“链接：{AI 摘要}”，旧快照没有摘要时显示安全域名。
- [x] 只显示 `http` 与 `https` 链接。
- [x] 转发邮件的接收时间使用 IMAP `INTERNALDATE`，不会误用原邮件 `Date`。
- [x] 同一来源域名不再生成多个相互重叠的来源名；既有类别不进入建议队列。
- [x] 可以查看历史报告，并兼容缺少新字段的旧快照。
- [x] 用户可在报告或邮件详情页标记本地已读；后续扫描不再显示。
- [x] 用户可以在已读管理页移除记录；下次扫描恢复显示该邮件。
- [x] 所有 Python 测试通过，前端无浏览器控制台错误。
- [x] 首页、报告、历史报告、已读管理和邮件详情各有截图；320、768、1024、1440px 没有横向溢出。
